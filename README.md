# Site Honu Kai Va'a (versão 2)

Site institucional, reservas, área do aluno e painel, em Next.js estático sobre o Supabase.
As regras de reserva e as permissões ficam no banco. Não coloque chaves secretas neste projeto.

- Rodar no computador: `INICIAR.bat` (Windows) ou `npm install` e `npm run dev`.
- Compilação: o fluxo "Compilar site v2" do GitHub Actions gera a pasta `out/`.
